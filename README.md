# 취업 트래커 - 채용공고 관리 시스템

## 시작하기

### 1. OpenAI API 키 설정
`backend/.env` 파일 생성:
```
OPENAI_API_KEY=sk-여기에붙여넣기
```

### 2. 백엔드 실행
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### 3. 프론트엔드 실행
```bash
cd frontend
npm install
npm run dev
```

브라우저에서 **http://localhost:5173** 접속

## 주요 기능

| 기능 | 설명 |
|------|------|
| 📅 캘린더 | 마감일 기준 공고 시각화, D-day 표시 |
| ➕ 공고 추가 | URL 입력 시 자동 파싱 (사람인/잡코리아/자체 채용) |
| 📋 공고 상세 | 공고 내용, 자격요건, 자기소개서 문항 |
| ✍️ AI 자소서 | GPT-4o가 내 정보 + 공고 기반 초안 생성 |
| 🏢 기업 분석 | AI 인재상 분석, 자소서 작성 방향 |
| 📰 뉴스 | 기업별 최신 뉴스/동향 자동 수집 |
| 👤 내 정보 | 학력/경력/스킬 등 프로필 관리 |

## 공고 추가 방법
1. 사이드바 **+ 공고 추가** 클릭
2. 사람인/잡코리아/기업 자체 채용 URL 붙여넣기
3. 마감일 입력 → 저장

## 자기소개서 작성 흐름
1. **내 정보** 페이지에서 프로필 작성
2. 공고 상세 → **자기소개서** 탭
3. 문항별 **AI 초안 생성** 클릭
4. 글자 수 제한 설정 가능
